## 🔄 Filosofía y Flujo de Aprendizaje

```text
 ┌──────────────┐      ┌──────────────┐      ┌──────────────────┐
 │  INVESTIGAR  │ ───> │  CONSTRUIR   │ ───> │ HALLAR PROBLEMA  │
 └──────────────┘      └──────────────┘      └─────────┬────────┘
        ▲                                              │
        │              ┌──────────────┐                │
        └───────────── │   MEJORAR    │ ◄──────────────┘
          (Iterar)     └──────────────┘
```

1. **Investigar:** Obtener el contexto y las bases necesarias sin caer en parálisis por análisis.
2. **Construir:** Escribir código y poner a prueba la hipótesis con un prototipo funcional.
3. **Encontrar el problema:** Descubrir las limitaciones técnicas reales en el entorno de ejecución.
4. **Profundizar:** Investigar con preguntas concretas generadas por la práctica.
5. **Resolver & Mejorar:** Refactorizar, optimizar y consolidar el aprendizaje en el código.
